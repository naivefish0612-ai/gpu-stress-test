# Security Policy

## Supported Versions

Security fixes target the latest version on the default branch.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub private vulnerability reporting when it is available for this repository. If it is not available, contact the core maintainer through GitHub and request a private disclosure channel.

Include:

- Affected files or versions.
- Steps to reproduce.
- Impact and risk level.
- Any suggested fix or mitigation.

The maintainer will acknowledge valid reports, coordinate fixes, and disclose details after users have a reasonable update path.
